# Win-back AI loop

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues (`Mo3azAqeed/Win-back-AI-loop`), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root, created lazily as terms and decisions get settled. See `docs/agents/domain.md`.

### Technical product manager notes

`docs/technical-product-manager-discussion.md` is the founder's story of how this work is run. After each ticket, decision or notable event, add a dated line to its Log (newest first). When something would make a good interview story (a decision made with evidence, a problem found and how it was handled), add it to "Stories for interviews": situation, what was done, result.
